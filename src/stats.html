Engagement counts are anonymous tallies, nothing about who played. Views: game page opened (once a day per browser). Started: first tap or key press in the game. Finished: the game's end screen appeared. Replays: Play Again pressed. Came back: someone who had played this game on an earlier day played it again (once a day). Next: a related or Up Next game picked from it. Amazon: an Amazon link clicked after playing it. Tap a column to sort.

Where players come from is where each browser's first visit came from (a YouTube link, a Pinterest pin, Google…), so someone who found you on YouTube and comes back later still counts as YouTube. A visit is one browser on one day. Links you post can carry ?s=yt, ?s=pin, ?s=fb, ?s=ig or ?s=tt to make sure they're credited. Source counting started on the day this version went live.

A play is one person opening a game on a given day, so refreshing or replaying the same game that day doesn't add more. Days run on UTC time (they roll over at 7pm Central). New games show a per-day average since they were added, so you can compare them fairly. Tap a game for its daily trend.
