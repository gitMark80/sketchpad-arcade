Crayon Code

Crack the secret row of crayon colours. Each guess tells you how close you are.

How to play

  • Tap crayons to fill the empty spots in your row, then tap Check. Tap a spot to clear it.
  • A filled dot means a crayon is the right colour in the right spot.
  • An open dot means the colour is in the code but in a different spot.
  • The dots aren't in the same order as your crayons, so you have to work out which is which.
  • Crack the code before you run out of rows. On Hard, a colour can be used more than once.
